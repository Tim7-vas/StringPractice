# Работа со строками в C# (StringPractice)

Практическая работа по изучению внутреннего устройства строк в .NET (`System.String`), способов конкатенации, класса `StringBuilder`, парсинга, работы с Unicode и потокобезопасности. Проект разработан в среде **Visual Studio** с использованием модели ветвления **Git Flow**

## Реализованные разделы

### Практический блок (`PracticeExamples.cs`)
- Демонстрация неизменяемости `string` и работы пула интернирования (`string.Intern`, `object.ReferenceEquals`)
- Сравнение производительности конкатенации через оператор `+=` в цикле и `StringBuilder` с помощью `Stopwatch`
- Разбор и сборка текста с помощью `Split`, `Trim`, `ToUpper` и `string.Join`
- Многопоточная сборка строки через `Parallel.For` с синхронизацией `lock`
- Работа со срезами без аллокаций (`ReadOnlySpan<char>`) и подсчёт графем Unicode (`StringInfo`)

### Самостоятельные задания
1. **Анализатор текста (`TextAnalyzer.cs`)** — подсчёт символов (всего и без пробелов), слов, предложений, поиск самого длинного и короткого слова, а также вывод топ-5 наиболее частых слов без учёта регистра
2. **Генератор отчётов (`ReportBuilder.cs`)** — формирование форматированного табличного отчёта о продажах с выравниванием колонок (`PadRight`, `PadLeft`) через `StringBuilder` и сохранением результата в файл `sales_report.txt`
3. **Шифр Цезаря (`CaesarCipher.cs`)** — шифрование (`Encrypt`) и дешифрование (`Decrypt`) латинского текста со сдвигом `k` через преобразование `ToCharArray()` с сохранением регистров, пробелов, цифр и знаков препинания
4. **Парсер CSV (`CsvParser.cs`)** — посимвольный конечный автомат для корректного разбора строк с запятыми и экранированными кавычками внутри полей, а также метод обратной сборки CSV
5. **Многопоточный логгер (`ThreadSafeLogger.cs`)** — параллельная запись логов из нескольких потоков с демонстрацией гонки данных без синхронизации и стабильной работы при использовании `lock`
6. **Валидация и нормализация Unicode (`UnicodeHelper.cs`)** — проверка строки на соответствие нормальной форме C (`IsNormalized(NormalizationForm.FormC)`), приведение к `FormC` и подсчёт пользовательских символов (`StringInfo`) на примере составных символов и эмодзи

## Структура проекта
```text
StringPractice/
├── PracticeExamples.cs # Демонстрация теоретической и практической части
├── TextAnalyzer.cs # Задание 1: статистика и анализ текста
├── ReportBuilder.cs # Задание 2: генератор отчёта о продажах
├── CaesarCipher.cs # Задание 3: шифрование и дешифрование методом Цезаря
├── CsvParser.cs # Задание 4: разбор и сборка CSV-строк с кавычками
├── ThreadSafeLogger.cs # Задание 5: потокобезопасный логгер
├── UnicodeHelper.cs # Задание 6: нормализация и подсчёт символов Unicode
└── Program.cs # Точка входа и запуск всех модулей
```

## Запуск проекта в Visual Studio
1. Склонируйте репозиторий:
```bash
git clone https://github.com
```
2. Откройте файл проекта **`StringPractice.csproj`** в **Visual Studio**
3. Нажмите **`F5`** для запуска демонстрационной программы
